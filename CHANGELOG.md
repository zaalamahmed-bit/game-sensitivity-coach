# Changelog

## 1.0.0 — 2026-09-06

Initial public release of Game Sensitivity Coach.

- Agent workflow for discovering mouse settings, transferring sensitivity between games, and reviewing gameplay evidence.
- Bounded Windows recording with foreground gating, raw mouse input, and session integrity manifests.
- Portable HTML evidence reports and exact-frame exports for image-capable host agents.
- Read-only settings discovery with examples for THE FINALS, Battlefield 6, and Holdfast.
- Explicit sensitivity conversion models and guarded settings changes with backups and rollback.
- Synthetic examples, regression tests, and a reproducible ZIP distribution with SHA-256 checksums.

Live capture requires Windows and FFmpeg. Visual analysis is performed by the host agent. Game compatibility and any proposed improvement require verification on the target computer.
