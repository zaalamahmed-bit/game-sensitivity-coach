# Security

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/DenisSergeevitch/game-sensitivity-coach/security/advisories/new). Do not disclose exploit details in a public issue or pull request before they have been reviewed.

Include the affected release or commit, relevant command or component, expected impact, and minimal reproduction steps. Use synthetic files where possible. Redact usernames, local paths, account identifiers, and secrets; do not attach raw gameplay captures, private configurations, real saves, or backups.

Useful reports include unintended file access or modification, unsafe handling of untrusted session artifacts, and failures that bypass configuration integrity or rollback safeguards. General setup problems and feature requests belong in the public issue tracker with private information removed.

The project does not promise a response deadline. If a fix is published, its release notes or advisory will identify the affected behavior and remediation.
