    How to read this report

    A candidate is a foreground left-button-down packet. It may be a shot, a menu click, or another action. When recording all windows on the selected monitor, the recorder marks every packet as foreground.

    The nearest recorded capture midpoint links an input event to a video frame. A capture gap can compress wall time in constant-frame-rate playback; check the click-to-frame distance before drawing timing conclusions.

    Movement is measured in raw counts per device, with background and absolute-motion packets excluded. A reversal is a nonzero sign change on one axis, not an aim diagnosis. The recorder does not detect targets, hits, or scoped state, and it does not calculate recommended settings. The coach result above comes from a separate assistant assessment of the evidence.

    Offline report and recording. The coaching result is supplied by the assistant; no forms are required. Optional annotations can be exported from Detailed evidence tools.
